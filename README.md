DAT 260 – Emerging Technologies and Big Data

This repository highlights the skills and concepts I learned while completing DAT 260: Emerging Technologies and Big Data at Southern New Hampshire University as part of my Computer Science degree.

Course Overview

Throughout this course, I explored how organizations collect, manage, and analyze large amounts of data using modern technologies. I gained experience with Python, Pandas, Apache Spark, data visualization, cloud computing, and emerging technologies such as artificial intelligence and the Internet of Things (IoT).

Skills and Technologies

- Python: Working with datasets, organizing information, and performing data analysis.
- Pandas: Using DataFrames to filter, clean, group, and summarize data.
- Apache Spark: Reading datasets, working with distributed DataFrames, and exploring large-scale data processing.
- Data Visualization: Creating charts, graphs, and heatmaps using Matplotlib and Seaborn.
- Cloud Computing: Understanding cloud storage, deployment models, and their benefits for organizations.
- Machine Learning and AI:Exploring predictive analytics, machine learning concepts, and practical business applications.
- Internet of Things (IoT): Understanding how connected devices collect data and support business decisions.

Course Projects

Project One: Cloud Computing Evaluation

Evaluated cloud computing technologies, deployment models, and the challenges of managing big data. Explored how organizations can use cloud-based solutions to improve scalability, data storage, and accessibility.

Project Two: Big Data Tools and Emerging Technologies

Examined technologies such as Apache Spark, Hadoop, and NoSQL databases. Explored how AI, machine learning, and IoT can improve customer experiences, business strategies, and data-driven decision-making while considering cybersecurity and privacy.

What I Learned

This course helped me better understand how programming and data analytics work together. I gained hands-on experience working with datasets and learned how different technologies can be used to process information and identify patterns. I also developed a better understanding of the importance of data accuracy, security, and reproducibility.

Future Development

I plan to continue improving my Python and data analysis skills while building additional programming projects throughout my Computer Science degree.
